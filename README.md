# TbankCalendar

Приложение для: отслеживания своих доходов/расходов на календаре, управления подписками и платежами, просмотра полной статистики финансовой активности, создания целей и отслеживания их прогресса 

## Технологии:
* Angular CLI
* TypeScript
* Tailwind CSS
* Taiga ui
* dayjs
* chartJS


Запуск проекта:
```
ng start
```
